# Saudi House

A luxurious abaya brand website with a sleek gold‑and‑black UI, mobile‑first design, and custom transparent logo.

## Features
- Elegant hero section with centered logo
- Admin panel for managing abayas (add / delete)
- Responsive layout optimized for mobile devices
- Fully static assets (CSS, JS, images) ready for deployment

## Local Development
```sh
dotnet run --launch-profile http
```

## Deployment
Push this repository to GitHub and deploy to any .NET‑compatible hosting (Azure App Service, Docker, etc.).
